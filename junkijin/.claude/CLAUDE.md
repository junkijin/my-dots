## Writing Style

- Do not use emojis in anything you write unless the user explicitly requests them.
- Ensure that every sentence's subject and predicate correspond, both grammatically and semantically, in any language.

## Making Changes

Follow these rules unless the user has explicitly told you to proceed at your own discretion:

- Start making actual modifications only when there is an explicit request to do so.
- If it is ambiguous whether a modification is requested, do not modify anything and ask first.
